# Java Day 54 - Employee Leave Management System

## Description
A Java-based employee leave management application that allows employees to submit leave requests and administrators to approve or reject them.

## Features
- Apply for employee leave
- View all leave requests
- Search requests using Employee ID
- Approve pending leave requests
- Reject pending leave requests
- Save updated records permanently

## Files
- `Main.java` - Main Java program
- `leaves.txt` - Leave request records

## Requirements
- Java JDK

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Classes and Objects
- Constructors
- ArrayList
- File Handling
- Searching and Updating Records
- Exception Handling
